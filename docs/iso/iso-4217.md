# ISO 4217 (currency codes)

## Summary

ISO 4217 defines three-letter currency codes such as `EUR`, `USD`, and `GBP`. Mollie amounts are objects with `currency` (ISO 4217) and `value` (decimal string).

## Crate mapping

| Item | Location |
| --- | --- |
| Application type | `mollie_rs::Currency` (`src/money.rs`) |
| Amount helpers | `mollie_rs::Money`, `mollie_rs::AmountValue` |
| Generated wire enum | `types::Currencies` |
| Contracts | [`currency.md`](../contracts/currency.md), [`money.md`](../contracts/money.md), [`amountValue.md`](../contracts/amountValue.md) |

## Wire form

```json
{
  "currency": "EUR",
  "value": "10.00"
}
```

- Currency: three uppercase letters (ISO 4217 alpha)
- Value: decimal string with the scale expected for that currency (this crate currently enforces two fractional digits for the supported Mollie set)

## Validation in this crate

This SDK does **not** accept every ISO 4217 code. It accepts the currencies present on the checked-in Mollie OpenAPI enum:

`EUR`, `GBP`, `CHF`, `DKK`, `NOK`, `PLN`, `SEK`, `USD`, `CZK`, `HUF`, `AUD`, `CAD`

```rust
use mollie_rs::{Currency, Money};

let currency = Currency::parse("EUR")?;
assert_eq!(currency.code(), "EUR");
assert_eq!(currency.minor_units(), 2);

let amount = Money::new("EUR", "10.00")?;
# Ok::<(), mollie_rs::MollieError>(())
```

Unsupported codes (e.g. `ISK`) fail with `MollieError::InvalidRequest` at `Currency::parse` / `Money::new`.

## Mollie usage examples

### Payment / payment-link / refund / capture amount

```rust
use mollie_rs::{types, Money};

// Non-null amount (payments, refunds, captures, …)
let amount: types::Amount = Money::new("EUR", "10.00")?.into();

// Nullable amount (e.g. payment-link bodies)
let optional: types::AmountNullable = Some(Money::new("EUR", "10.00")?).into();
# let _ = (amount, optional);
# Ok::<(), mollie_rs::MollieError>(())
```

### Balance and settlement amounts

Response amounts are generated `types::Amount` values. Re-validate with `TryFrom`:

```rust
use mollie_rs::{types, Money};

let wire = types::Amount {
    currency: "EUR".into(),
    value: "42.00".into(),
};
let money = Money::try_from(wire)?;
assert_eq!(money.currency().code(), "EUR");
# Ok::<(), mollie_rs::MollieError>(())
```

### Application fee amounts

```rust
use mollie_rs::{types, ApplicationFee, Money};

let fee = ApplicationFee::new(Money::new("EUR", "1.00")?, "Platform fee")?;
let payment_fee: types::PaymentRequestApplicationFee = fee.clone().into();
let link_fee: types::CreatePaymentLinkBodyApplicationFee = fee.into();
# let _ = (payment_fee, link_fee);
# Ok::<(), mollie_rs::MollieError>(())
```

See also [`applicationFee.md`](../contracts/applicationFee.md).
