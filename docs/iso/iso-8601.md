# ISO 8601 (date and time)

## Summary

ISO 8601 is the international standard for date and time representations. Mollie API timestamps are ISO 8601 strings with an **explicit offset** (often `+00:00` / UTC). Calendar-only fields use `YYYY-MM-DD`.

## Crate mapping

| Item | Location |
| --- | --- |
| Instant (offset-aware) | `mollie_rs::DateTime` (`src/datetime.rs`) |
| Calendar date | `mollie_rs::Date` (`src/datetime.rs`) |
| Contract | [`docs/contracts/dateTime.md`](../contracts/dateTime.md) |
| Generated wire | plain `String` on many resources; some fields use `chrono::NaiveDate` |

## Wire form (examples from Mollie)

```text
2026-01-22T10:39:23+00:00
2026-07-13T12:00:00+00:00
2026-01-22T10:39:23Z
```

| Pattern | Type | Meaning |
| --- | --- | --- |
| `YYYY-MM-DDThh:mm:ss±hh:mm` | `DateTime` | Instant with explicit offset |
| `YYYY-MM-DDThh:mm:ssZ` | `DateTime` | Instant in UTC (`Z` → `+00:00` on format) |
| `YYYY-MM-DD` | `Date` | Calendar date only (`dueDate`, etc.) |

**Rejected:** naive datetimes without offset (`2026-01-22T10:39:23`), empty strings, and non-ISO forms.

## Validation in this crate

```rust
use mollie_rs::{Date, DateTime};

let created = DateTime::parse("2026-01-22T10:39:23+00:00")?;
// Assign onto string fields:
// payment_link.expires_at = Some(created.to_rfc3339());

let due = Date::parse("2026-07-13")?;
// fields that use chrono::NaiveDate:
// request.due_date = Some(due.as_naive());
# Ok::<(), mollie_rs::MollieError>(())
```

Helpers:

- `DateTime::now_utc()` — current UTC instant  
- `DateTime::from_utc` / `from_chrono` — from existing chrono values  
- `DateTime::to_rfc3339()` — stable wire string with numeric offset  
- `Date::from_ymd` / `as_naive` — calendar dates for generated `NaiveDate` fields  

Duration-like product strings (e.g. capture delay `"8 hours"`) are **not** ISO 8601 instants and are out of scope for these types.

## Mollie usage examples

- `createdAt`, `paidAt`, `canceledAt`, `authorizedAt`
- Payment-link `expiresAt`
- Settlement / balance reporting periods
- `dueDate` / other calendar dates → `Date`
